# CrudeEngine

A very *crude* engine designed as a framework to make games or build other engines on top of.

## About

This is my first attempt at making a C# game engine, coming from a background in Java engine development. The project is experimental and serves as a learning experience.
Feel free to explore, learn, and contribute if you wish!

- Built in C#
- Inspired by previous Java engine projects
- Intended as a personal project, but open to sharing progress

## Contributions

Pull requests are welcome, although I am not actively seeking external contributions. This is primarily a personal project that I am sharing, as a part of my further progression in game engine development

## Dependencies

- .NET 10.0
- All the necessary NuGet packages, which should be restored on clone

## Build Info

1. Clone the repository.
2. Open the solution in your preferred IDE (e.g., Visual Studio, Rider).
3. Restore NuGet packages.
4. Build the solution.
